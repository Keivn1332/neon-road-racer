# 霓虹公路

一款以繁體中文呈現的迷你瀏覽器賽車遊戲。閃避車流、收集星星，挑戰個人最佳分數。

## 開始遊玩

直接以瀏覽器開啟 [`outputs/index.html`](outputs/index.html)。

- 桌面：使用 `←` / `→` 或 `A` / `D` 換道。
- 手機：使用畫面上的方向按鈕，或在遊戲畫面上滑動。

## 發布

推送到 `main` 分支後，GitHub Actions 會自動發布 `outputs/` 到 GitHub Pages。也可從 Actions 頁面手動執行 `Deploy to GitHub Pages`。

第一次發布前，請在 repository 的 **Settings → Pages** 將 **Build and deployment → Source** 設為 **GitHub Actions**。

## 計畫

遊戲願景與路線圖見 [`knowledge/plan.md`](knowledge/plan.md)。
